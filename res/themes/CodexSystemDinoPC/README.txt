CODEX SYSTEM DINO PC
====================

Tema preparado para:
- Turing Smart Screen 3.5"
- 480x320 landscape
- LibreHardwareMonitor / PawnIO
- CPU, GPU, RAM, uptime, rede e relogio
- dinossauro pixel-art no rodape

INSTALACAO
----------
1. Extraia a pasta CodexSystemDinoPC para:

C:\TuringScreen\turing-smart-screen-python\res\themes\

Resultado esperado:

C:\TuringScreen\turing-smart-screen-python\res\themes\CodexSystemDinoPC\
  theme.yaml
  background.png
  dino.png
  preview.png
  README.txt

2. Abra PowerShell como Administrador:

cd C:\TuringScreen\turing-smart-screen-python
python configure.py

3. Selecione:
Theme: CodexSystemDinoPC
Hardware monitoring: Automatic / LibreHardwareMonitor
Ethernet interface: Ethernet

4. Save and run.

Observacao:
O dinossauro desta versao e estatico e faz parte do background.
Depois podemos adicionar uma versao animada andando, igual ao pato.

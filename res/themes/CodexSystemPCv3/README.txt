CodexSystemPCv3

Destino:
C:\TuringScreen\turing-smart-screen-python\res\themes\CodexSystemPCv3

Depois:
1. Execute python configure.py como Administrador.
2. Selecione Theme = CodexSystemPCv3.
3. Em Ethernet interface selecione "Ethernet".
4. Mantenha Hardware monitoring = Automatic/LibreHardwareMonitor.
5. Save and run.

A V3 usa:
- CPU load, temperatura e clock
- GPU load, temperatura e VRAM %
- RAM %, usada e total
- Uptime
- Download/upload Ethernet
- Relógio

O PawnIO precisa estar funcionando para CPU temperatura/clock.
